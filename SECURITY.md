# Security Policy

This policy applies to `open-eeg-synth`.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability):

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability** to open a private security advisory.
3. Include a description, affected versions, reproduction steps, and any
   suggested remediation.

This routes the report directly and privately to the maintainers.

## Response intent

This is a small project maintained by Peak Mind LLC. We aim to acknowledge new
reports within **5 business days** and to keep you updated as we triage,
confirm, and address the issue. Timelines for a fix depend on severity and
complexity; we will coordinate disclosure with you before any public
announcement.

## Supported versions

open-eeg-synth is pre-1.0 and evolving. Security fixes are applied to the **latest
released version only**. We do not backport fixes to older pre-1.0 releases —
please upgrade to the latest version to receive security updates.
