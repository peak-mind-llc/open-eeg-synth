# Governance

This document describes how decisions are made for
`open-eeg-synth`.

## Model: benevolent dictator (BDFL)

The project currently operates under a benevolent-dictator model. **Peak Mind
LLC**, through its engineering lead, holds final merge authority over this
package and the package surface. This keeps the project's direction coherent
while it is young and the contributor base is small.

## How decisions are made

- **Day-to-day changes** — Anyone may open an issue or pull request. Maintainers
  review for correctness, scope, test coverage, and fit with the package's
  direction. Discussion happens in the open on GitHub issues and PRs.
- **Direction and design** — Larger or breaking changes should start as an issue
  or discussion so the approach can be agreed before significant work begins.
  Peak Mind LLC makes the final call when there is no clear consensus.
- **Merge authority** — Peak Mind LLC (engineering lead) approves and merges
  changes to the package. Contributors are credited via commit authorship and
  the DCO `Signed-off-by` trailer.

## How this may evolve

The BDFL model is a starting point, not a permanent structure. As the community
and contributor base grow, we expect to formalize governance further — for
example, by recognizing trusted maintainers with merge rights, documenting a
maintainer team, and adopting a more distributed decision-making process. Any
such change will be announced and documented in this file.
